## Target Visual Characteristics

### Environment
- Warm daylight
- Blue/cyan sky
- Warm orange/yellow sunlight
- Hand-painted appearance
- Stylized stone streets
- Detailed wooden buildings
- Japanese/Konoha architectural language
- Vegetation (cedar, sakura, shrubs, grass)
- Hanging signs
- Lanterns (warm amber glow)
- Banners
- Shops
- NPCs (villagers, shinobi, shopkeepers)
- Distant mountains
- Hokage Monument on central axis
- Atmospheric depth (five-tier: foreground, midground, background landmarks, vista, sky)
- Colorful but controlled palette
- **NO** photorealistic materials
- **NO** black void
- **NO** white overexposure

### Characters
- Clearly visible
- Stylized anime proportions (head-to-body ~1:5.5 for Genin)
- Recognizable silhouettes
- Detailed clothing
- Proper hair (spiky, stylized, character-specific)
- Facial features (expressive anime eyes, mouth)
- Village headband (metallic Konoha)
- Weapons/pouches
- Cloth layers
- Anime facial shading
- Expressive animation
- Combat-ready skeleton
- Real locomotion (shinobi movement)

### Camera
- Third-person
- Naruto visible from behind
- Character occupies ~25-32% screen height
- Environment remains visible
- Camera slightly elevated
- Action-RPG framing
- Soft camera follow
- Cinematic but playable

### UI
- Character portrait
- Level indicator
- HP bar
- Chakra bar
- Party switching (character icons)
- Jutsu icons
- Readable key prompts
- Minimap
- Mission objective
- Boss health (when applicable)

### Gameplay
- Running, walking, jumping, dodging
- Attacks, combos
- Jutsu (hand-sign/QTE systems)
- Chakra charging
- Substitutions
- Transformations
- Boss encounters
- NPC interactions
- Exploration

## Rejected Visual Directions

| Rejected Style | Reason |
|---|---|
| Photorealistic AAA | Wrong genre — this is anime, not military sim |
| PBR showcase | Materials must be stylized, not physically accurate |
| Dark/gritty realistic | Must be warm, colorful, inviting |
| Flat 2D cartoon | Must be full 3D with depth |
| Mobile chibi | Proportions must be natural anime |
| Neon debug primitives | Production assets only |
| Black void | Always requires sky, atmosphere, world |
| White overexposure | Exposure must be controlled |
| Generic Unreal demo | Must have authored EOS identity |

---

## Visual Continuity

Every location in the game must share the same visual language. This means Suna, Kiri, Kumo, Iwa, Ame, and all future regions use the same rendering pipeline, material system, character shading, and camera language — only the environmental content (architecture, palette, vegetation, weather) changes.

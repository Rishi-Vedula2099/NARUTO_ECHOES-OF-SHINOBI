# PROJECT AUTHORITY & GOVERNANCE

Project: NARUTO: ECHOES OF SHINOBI  
Framework: Unreal Engine 5.8 / C++ / GAS / Stylized 3D Anime Action RPG  

## CORE MANDATES
1. **Preserve Operational Gameplay Framework:** Never break, discard, or rewrite the C++ ability system, combat architecture, state machines, progression, HUD logic, or input handlers.
2. **Visual Completion Requires Production Assets:** A C++ class, Blueprint actor, or Outliner entry is meaningless without the underlying production mesh, material, and animation rendering visually in the viewport.
3. **Strict Gate Progression:** Development is gated. Never advance to full rosters, multiple stages, or secondary villages until `L_Konoha_GoldenStreet` visually matches the Visual DNA.
4. **Mandatory Failure Memory:** Every visual failure identified from screenshots must be logged in `Docs/Reports/VISUAL_FAILURE_MEMORY.md` with root cause, failed criterion, and permanent prevention rule.
